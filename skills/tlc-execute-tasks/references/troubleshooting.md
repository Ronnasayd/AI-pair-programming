# Troubleshooting

| Symptom                                                                         | Cause                                                                                 | Fix                                                                                                                                                                |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Missing `.specs/features/{TAG}/spec.md`                                         | Feature never went through the Specify phase                                          | Report exact missing path, do not proceed -- run tlc-spec-driven Specify first                                                                                     |
| No matching tag in `.taskmaster/tasks/tasks.json`                               | Feature was never converted to taskmaster, or tag name mismatch                       | Run `tlc-tasks-to-taskmaster` first, or proceed without sync if the user doesn't want taskmaster tracking for this feature                                         |
| `set_task_status` returns success but tasks.json unchanged                      | `tag` param omitted from the call                                                     | Always pass `tag` -- required for both MCP backend and file write                                                                                                  |
| Taskmaster shows a task as `done` but tlc-spec-driven's Verifier later flags it | Sync happened after the task's own gate passed but before the end-of-run Verifier ran | Revert that task's status to `pending` when the Verifier raises a gap, then re-sync to `done` once the fix commit lands (see Status mapping in SKILL.md)           |
| Taskmaster and tasks.md disagree about what's pending                           | Taskmaster tag is stale (edited by hand, or a previous run didn't sync)               | Taskmaster is a mirror, not a source of truth -- tlc-spec-driven's own state (spec.md, git history, task commits) decides what's pending, never the taskmaster tag |
