# Troubleshooting

| Symptom                                                                                         | Cause                                                                              | Fix                                                                                                     |
| ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Setup aborts immediately with dirty tree                                                        | Uncommitted changes exist on current branch before run                             | Stop, ask user to commit/stash first — never auto-stash or discard                                      |
| Missing `.specs/features/{TAG}/design.md` or `spec.md` or `.taskmaster/execution/metadata.json` | Feature never went through spec/design/tasks phases                                | Report exact missing path(s), delete the run branch, do not proceed                                     |
| `set_task_status` returns success but tasks.json unchanged                                      | `tag` param omitted from the call                                                  | Always pass `tag` — required for both MCP backend and file write                                        |
| Wave N+1 executors appear to start before wave N finishes                                       | Agent calls for wave N+1 fired in same message as wave N                           | Wait for all wave-N results before issuing any wave-N+1 Agent call                                      |
| Executor reports failure with no clear cause                                                    | Context-map missing a needed excerpt (spec/design/tasks.md section or source file) | Verify prompt included the task's context-map excerpts, not a full-file dump or an under-scoped summary |
| `git merge --no-ff` conflicts on a task branch                                                  | Conflicts with changes from an earlier merged task                                 | Hand off to `resolve-merge-conflicts` skill, do not force-merge or discard                              |
| Stray worktree/branch left after a run                                                          | Cleanup step skipped after failure/abort                                           | `git worktree remove <path>` + `git branch -D <task-branch>`; never `rm -rf` the worktree directory     |
| User wants partial rollback after Abort                                                         | Abort only stops further waves                                                     | Summary reflects waves 0..N-1 only; already-applied diffs on the run branch are not undone              |
| `--no-ff` merge back leaves unexpected conflicts                                                | Original HEAD moved (new commits) since run branch created                         | Surface conflicts to user, do not auto-resolve; user decides whether to rebase run branch first         |
