# Hooks — Environment Variables

Env vars read by scripts in `hooks/scripts/`. All optional unless noted.

| Variable                        | Script                                                         | Default                                                                         | Purpose                                                                                                                                                                                                       |
| ------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CLAUDE_PROJECT_DIR`            | `protect_branches.py`, `protect_files.py`, `smart_approve.py`  | `os.getcwd()`                                                                   | Project root. Set by Claude Code itself; stable for the whole session.                                                                                                                                        |
| `CLAUDE_SETTINGS_PATH`          | `smart_approve.py`                                             | `~/.claude/settings.json`                                                       | Global settings.json path override.                                                                                                                                                                           |
| `AI_PROJECT_DIR`                | `skill_activation.py` (required), `checklist_context_watch.py` | none (`skill_activation.py` raises `KeyError` if unset)                         | Root used to locate `.claude/skills/`.                                                                                                                                                                        |
| `CLAUDE_TRANSCRIPT_PATH`        | `session_end.py`                                               | none                                                                            | Fallback transcript path when stdin JSON has no `transcript_path` (backwards compat).                                                                                                                         |
| `CLAUDE_PACKAGE_MANAGER`        | `utils.py` (`_get_runner_from_package_manager`)                | inferred from `package.json` `packageManager` field, else `npx`                 | Force package-manager runner (e.g. `pnpm`, `yarn`).                                                                                                                                                           |
| `PROTECTED_BRANCHES`            | `protect_branches.py`                                          | `main,master,develop,homolog`                                                   | Comma-separated override of protected branch names.                                                                                                                                                           |
| `PROTECT_FILES_EXTRA_ALLOWED`   | `protect_files.py`                                             | none                                                                            | Colon-separated extra glob patterns allowed past the file-protection hook. Must be exported **before** launching Claude Code — the hook process doesn't inherit vars `export`ed from inside a Bash tool call. |
| `SMART_APPROVE_VERBOSE`         | `smart_approve.py`                                             | disabled                                                                        | `1`/`true`/`yes` enables verbose approval-decision logging.                                                                                                                                                   |
| `JSON_COLORIZE`                 | `log_hooks.py`                                                 | disabled                                                                        | If set (truthy), pretty-print/colorize logged JSON payloads instead of raw dump.                                                                                                                              |
| `TMUX`                          | `dev_server_tmux_check.py`                                     | none                                                                            | Standard tmux env var; presence + valid socket path detects tmux session.                                                                                                                                     |
| `STY`                           | `dev_server_tmux_check.py`                                     | none                                                                            | Standard GNU screen env var; presence detects screen session.                                                                                                                                                 |
| `JEST_COVERAGE_CMD_INCREMENTAL` | `jest_coverage_incremental.py`                                 | `NODE_ENV=test node_modules/.bin/jest --passWithNoTests --runInBand`            | Override base runner command only. `--findRelatedTests <rel_path> --coverage --coverageDirectory=<dir> --collectCoverageFrom=<rel_path>` are always appended after it.                                        |
| `JEST_COVERAGE_CMD_FULL`        | `jest_coverage_session_end.py`                                 | `NODE_ENV=test node_modules/.bin/jest --coverage --passWithNoTests --runInBand` | Override full-project jest command run at session end. Plain string, no template substitution.                                                                                                                |
