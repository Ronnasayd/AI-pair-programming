## Always Use Interactive Question Tools

Use an interactive question tool for every user question — no exceptions.

Covers clarifications, options, confirmations, preference checks,
all user interactions.

- **Claude**: `AskUserQuestion`
- **Other environments**: equivalent interactive tool
- **Fallback**: labeled options (A, B, C... Z)

Never ask a plain-text question if an interactive tool exists.

Multiple questions: use `grilling` skill.

Ask in clear, technical language.
